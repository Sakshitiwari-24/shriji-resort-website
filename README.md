## Overview

The official website for **Shriji Resorts & Marriage Garden**, located on Shiv Nagar Road near Makhan Lal Chaturvedi University, Allahabad Road, Rewa, Madhya Pradesh (`486001`).

Designed with clear, easy-to-read copy, 100% responsive layouts from `320px` mobile screens to large desktops, instant section navigation, and complete local/technical SEO for Rewa wedding and banquet searches.

---

## Key Features

- **Clean Sticky Navigation (`Navbar.jsx`)**: Frosted-glass header with Story, Spaces, Rooms, Events, Gallery, and Contact links, instant section jump transitions, and a full-screen mobile menu drawer.
- **Hero & Quick Date Check (`HeroSection.jsx`)**: Video background hero with an interactive date, event type, and guest count bar plus direct WhatsApp enquiry.
- **About & Capacity Highlights (`IntroSection.jsx`)**: Overview of the 35,000 sq ft open green lawn (up to 2,000 guests), 10,000 sq ft AC banquet hall (400–600 guests), swimming pool, and 25+ AC guest rooms.
- **Interactive Spaces Explorer (`SpacesSection.jsx`)**: Expanding horizontal cards on desktop and touch-friendly accordion cards on mobile covering the Main Marriage Lawn, AC Banquet Hall, Poolside & Haldi Deck, Garden Tent Lawn, and AC Guest Rooms.
- **Guest Stay (`AccommodationsSection.jsx`)**: Showcase of Deluxe AC Rooms, Poolside AC Rooms, and Family & Bridal Suites with amenities and direct suite enquiry.
- **Events We Host (`EventsSection.jsx`)**: Filterable showcase for Weddings & Receptions, Engagements & Ring Ceremonies, Birthday Parties, Retirement & Office Events, Mundan & Family Pooja, and Anniversaries & Sangeet Nights.
- **Photo Gallery (`MomentsGallerySection.jsx`)**: Category-filtered photo gallery with a full-screen lightbox and keyboard navigation (`Esc`, `←`, `→`).
- **Wedding Day Timeline (`ExperienceSection.jsx`)**: 4-step walkthrough of how an event flows at Shriji Resort from Barat arrival and parking to mandap ceremony, AC banquet dinner, and guest stay.
- **Guest Reviews (`ReviewsSection.jsx`)**: Verified reviews from host families across Rewa and nearby cities.
- **Booking Enquiry & Direct Phone Lines (`BookingEnquirySection.jsx`)**: Form with validation, WhatsApp prefilled enquiry submission, and direct tap-to-call buttons for all 3 official booking desks.
- **Google Map, Directions & FAQs (`ContactLocationSection.jsx`)**: Embedded Google Map with GPS directions and an interactive Common Questions accordion.
- **Mobile Quick Action Dock (`FloatingActions.jsx`)**: Sticky bottom action bar on mobile for instant Call, WhatsApp, and Book access.

## SEO & Performance

- Complete primary, local Rewa geo (`IN-MP`), Open Graph, and Twitter Card meta tags in [`index.html`](./index.html).
- Rich JSON-LD `@graph` structured data (`EventVenue`, `Resort`, `LocalBusiness`, `WebSite`, and `FAQPage`).
- Search engine crawl files included: [`public/robots.txt`](./public/robots.txt), [`public/sitemap.xml`](./public/sitemap.xml) (with image sitemap entries), and [`public/site.webmanifest`](./public/site.webmanifest).
- Single `<h1>` heading hierarchy and fast preloader (`500ms`) for strong Core Web Vitals.

## Running Locally

### Prerequisites
- [Node.js](https://nodejs.org/) v18+
- `npm`

### Commands

```bash
# Clone the repository
git clone https://github.com/Sakshitiwari-24/shriji-resort-website.git
cd shriji-resort-website

# Install dependencies
npm install

# Start development server (http://localhost:3000)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment on Vercel

This project includes [`vercel.json`](./vercel.json) configured for Vite SPA routing.

```bash
# Deploy directly to Vercel production
npx vercel --prod
```
